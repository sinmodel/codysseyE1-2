# Python · JSON · Git 명령어 퀴즈

Python, JSON, Git, GitHub의 기초 개념과 명령어를 사지선다형으로 연습하는 퀴즈 게임입니다. 기본 화면은 마우스로 사용하는 Tkinter 대시보드이며, 과제용 콘솔 실행 모드도 제공합니다.

## 퀴즈 주제

프로그래밍과 버전 관리의 기초를 문제로 풀어 보며 과제 학습과 시험 준비를 함께 하기 위해 이 주제를 선택했습니다. 명령어의 뜻뿐 아니라 상황에 맞는 명령어를 고르는 문제도 다룹니다.

## 실행 방법

Python 3.10 이상에서 프로젝트 폴더로 이동한 뒤 실행합니다. 기본 실행은 대시보드입니다.

```powershell
py -3 main.py
```

콘솔 모드는 다음과 같이 실행합니다.

```powershell
py -3 main.py --cli
```

## 기능

- Python, JSON, Git, GitHub 기초 문제 62개 (주제별 15~16개)
- 주제 선택, 문제 수 선택, 무작위 출제
- 마우스로 보기 선택 및 정답 확인
- 숫자 또는 보기 문구로 답하는 콘솔 모드
- 퀴즈 추가, 목록 확인, 최고 점수 및 기록
- JSON 파일 저장 및 불러오기, 손상된 파일의 기본 데이터 복구

## 데이터 파일

게임 데이터는 프로젝트 루트의 `state.json`에 UTF-8 인코딩으로 저장됩니다. 이 파일은 사용자별 퀴즈와 점수 데이터이므로 Git 저장소에는 올리지 않습니다.
