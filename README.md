# Python · JSON · Git 명령어 퀴즈

Python, JSON, Git, GitHub의 기초 개념과 명령어를 사지선다형으로 연습하는 콘솔 퀴즈 게임입니다.

## 퀴즈 주제

프로그래밍과 버전 관리의 기초를 문제로 풀어 보며 과제 학습과 시험 준비를 함께 하기 위해 이 주제를 선택했습니다. 명령어의 뜻뿐 아니라 상황에 맞는 명령어를 고르는 문제도 다룹니다.

## 실행 방법

Python 3.10 이상에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
py -3.13 main.py
```

## 기능

- 준비 중: 퀴즈 메뉴와 사지선다 문제
- 준비 중: 퀴즈 추가, 목록, 최고 점수
- 준비 중: JSON 파일 저장 및 불러오기

## 파일 구조

```text
python-command-quiz/
├── .gitignore
├── README.md
└── main.py
```

## 데이터 파일

게임 데이터는 프로젝트 루트의 `state.json`에 UTF-8 인코딩으로 저장할 예정입니다. 이 파일은 사용자별 퀴즈와 점수 데이터이므로 Git 저장소에는 올리지 않습니다.
