# 기초 명령어 퀴즈 게임 1.0

Python, JSON, Git, GitHub의 기초 개념과 명령어를 연습하는 콘솔 퀴즈 게임입니다.
메뉴에서 숫자를 입력해 퀴즈를 풀고, 문제를 추가하거나 점수를 확인할 수 있습니다.

## 실행 방법

Python 3.10 이상에서 이 폴더로 이동한 뒤 실행합니다.

```powershell
py -3 main.py
```

## 기능

- 숫자 메뉴로 퀴즈 풀기, 문제 추가·삭제, 목록 확인, 최고 점수 확인 및 종료
- 삭제 대상과 확인 절차를 거친 뒤 저장 파일에 반영
- Python, JSON, Git, GitHub 기초 퀴즈 62개
- 문제 순서를 무작위로 선택하고 출제할 문제 수 지정
- 잘못된 메뉴, 문제 수, 정답 입력을 안내하고 다시 입력
- 퀴즈와 점수 기록을 JSON 파일에 저장하고 다음 실행 때 불러오기
- 저장 파일이 없거나 손상된 경우 기본 퀴즈로 시작
- Ctrl+C 또는 입력 종료 시 저장을 시도하고 안전하게 종료

version-1.0/

## 클래스 역할

- `Quiz`는 한 문제의 내용, 네 가지 선택지, 정답과 주제를 관리합니다.
- `QuizGame`은 퀴즈와 점수를 저장하고 불러오며, 메뉴·퀴즈 진행·문제 추가·삭제·목록·점수 확인을 담당합니다.
- `console_ui.py`는 실행 진입점에서 `QuizGame`의 콘솔 실행을 연결합니다.

## 데이터 파일

`state.json`은 이 폴더에 생성되며, 추가한 퀴즈와 최고 점수 및 플레이 기록을
UTF-8 형식으로 저장합니다. 사용자 데이터 파일은 Git에 포함하지 않습니다.
